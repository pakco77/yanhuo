# 烟火侠客 · 文字版

吃饭、睡觉、行走江湖的文字小游戏。

- 网页地址：https://pakco77.github.io/yanhuo/
- iPhone：用 Safari 打开，先点「分享 → 添加到主屏幕」（新版 iOS 的「分享」在地址栏旁的「···」里），以后都从主屏幕图标进去玩。主屏幕图标里的存档和 Safari 里的是分开的：已经在 Safari 里玩过的话，先在 Safari 里点最底下「备份存档 → 复制存档码」，再打开图标，在开头点「恢复存档」粘进去。删掉主屏幕图标会连进度一起删掉。
- 安卓：用 Chrome 打开，点菜单里的「添加到主屏幕」。
- 进度只存在这台手机里。游戏底部的「备份存档」可以下载存档文件或复制存档码，换手机时在新手机上恢复。
